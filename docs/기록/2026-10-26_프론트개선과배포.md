### 바다 쪽 경계와 격자 — 화면에서 데이터로

처음에는 화면에서 풀려고 했다. 경계를 흐려 둥글리고, 칸 밖 땅은 가장 가까운 칸 값(1km 안)으로 칠했다. 사용자가 확대해 보며 계속 빈 곳을 찾아냈다.

- 월미도 부근처럼 **눌리는데 값이 없는 땅**: 격자를 "칸 중심이 육지인 칸"만으로 만들어서, 경계 안 땅의 약 11%가 어느 칸에도 안 들었다(200m 간격 표본)
- 경인항·인천항 부두·송도 남쪽처럼 **눌러도 범위 밖인 땅**: 행정경계(SGIS)에 아직 어느 동에도 들지 않은 매립지가 있었다

사용자 기준은 "격자는 내부 계산용이라 많든 적든 상관없고, 일반 사용자가 인천 땅이라고 보는 곳은 전부 눌리고 값이 나와야 한다"였다. 그래서 데이터를 고쳤다(원래 저장소 `dff3d37`·`5541c69`).

- `Tools/make_mockup_boundary.py`: OpenFreeMap 벡터 타일의 water 층(class=ocean)을 받아, 바다가 아니고 어느 행정동에도 없고 내륙에 300m 안으로 붙은 조각을 가까운 구에 붙임. 타일은 외부 패키지 없이 직접 읽었고, Node 디코더로 받은 것과 넓이가 같은지 대조했다
- `Tools/make_service_shared.py`: 격자를 경계와 조금이라도 겹치는 칸 전부로 → **456칸**. 경계 안 17,757개 점이 모두 어느 칸에 든다
- 폭 2km가 넘는 만(인천항 남쪽 부두~크루즈터미널)은 둥글리기로 안 메워졌다. 경계의 오목 껍질에서 바다인 부분만 더한 화면용 경계 `display`를 따로 두었다(비율 0.02·0.05·0.1을 그려 비교해 0.05). 클릭 판정은 `area` 그대로라 메운 바다는 눌러도 범위 밖이다

### 시연까지 배포만 — `/api/point`·`/api/health`

배포 전에 꼭 필요한 것만 추렸다. `/api/point`가 없으면 클릭해도 "상세 정보 준비 중"만, `/api/health`가 없으면 "갱신 상태 확인 불가"가 계속 떠 있다. CORS는 같은 주소로 배포하면 필요 없어서 뺐다.

- `/api/health`: `stale` = 낮에 40분 넘게 추정값 없음. 밤과 **해 뜬 직후 40분**은 false(새벽 첫 회차 전 거짓 경고 방지). 낮·밤은 수집기와 같은 태양고도 식(`server/sun.py`)

### 수집 VM에 같이 올리기

계정 검토: 사용자 기존 GCP 계정은 결제 인증(카드 사진·신분증)에 막혔다. 다른 구글 계정은 같은 사람이라 GCP 무료 체험 자격이 안 된다. 조원 중 무료 체험이 되는 사람이 없었고, Azure for Students는 가입이 까다로웠다. 수집 VM에 하나 더 만들면 무료 티어를 넘는다.
남은 길이 수집 VM에 같이 올리기(추가 비용 0)였다.

| 수집 VM 실측 (10/26 22:10) | 값 |
|---|---|
| 메모리 | 953MB 중 사용 465, 여유 487 |
| 추정기 피크 | 353MB(10/13 실측), 상한 600MB |
| 스왑 | 없음 |

낮 피크에 서비스까지 얹으면 넘칠 수 있었다. 스왑 2GB·swappiness 10·수집기 `OOMScoreAdjust=-900`를 먼저 걸었다(수집기 재시작 없이 `/proc`로 바로 적용).
사용자가 "스왑을 걸면 확실히 문제없나"를 물어, 강제 종료는 막지만 느려질 수 있고 계속 커지는 프로세스는 못 막는다고 답했다. 그래서 서비스마다 상한을 둔다.

배포(10/27 00시대): PostgreSQL 16(버퍼 32MB, 연결 20), API(`MemoryMax=200M`, `OOMScoreAdjust=500`), Caddy(120M, `/web/`·경계 파일·`/api/*`만 내보냄). 도메인은 DuckDNS `incheon-air`.
추정기는 같은 VM이라 `http://127.0.0.1:8001`로 보내게 했다. 인터넷·방화벽을 거치지 않고 토큰이 밖에 안 나간다. DB 비밀번호와 수신 토큰은 서버에서 만들어 `.env`에만 넣었다.

## 정정된 판단

- **칸 밖 땅을 "1km 안 가장 가까운 칸"으로 칠하던 방식을 버렸다.** 화면만 그럴듯해지고 백엔드 `/api/point`가 같은 규칙을 따로 흉내 내야 했다. 매립지는 애초에 경계 밖이라 이 방식으로는 안 풀렸다. 데이터(경계·격자)를 고치는 쪽이 맞았다
- **처음 경계 둥글리기가 땅을 깎았다.** 흐린 경계를 다시 또렷하게 할 때 좁은 터미널·송도 끝이 지워졌다. 원래 경계와 합쳐 메우기만 하도록 고쳤고, 가림막과 구름이 경계를 따로 둥글려 어긋나던 것도 같은 마스크를 쓰게 했다
- **컴퓨터 첫 화면 줌을 고정값(+1.1)으로 넣었다가 넓은 모니터에서 아래가 잘렸다.** 화면 비율마다 계산하는 방식으로 바꿨다
- **컴퓨터 클릭을 "패널을 뺀 영역 가운데"로 맞췄더니 왼쪽으로 치우쳐 보였다.** 컴퓨터 패널은 작은 카드라 화면 가운데가 맞았다
- **애니메이션을 금혁 님 코드에서만 풀었는데 여전히 안 보였다.** MapLibre가 따로 같은 신호를 본다는 것을 라이브러리 코드에서 확인했다
- **수신 토큰은 "A가 정해 팀장에게 알려 줌"이었는데,** 배포를 팀장 쪽에서 하면서 서버에서 만들어 양쪽 `.env`에 넣었다
