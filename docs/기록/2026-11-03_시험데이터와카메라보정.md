# 2026-11-03 · 시험 데이터와 카메라 보정

> 9주차 · 전시 준비 모델 실험 첫날. 시험 데이터를 10/20~11/1로 고정하고 지금 모델(ⓐ)을 채점했다. 카메라별 보정(M2)을 얹고, 날 수만 늘린 대조군(ⓑ)을 학습했다. 즉석 추론이 1GB VM에서 도는 것도 확인했다.
> 11/4에 썼다. 11/3 오후 작업 일부는 원래 세션에서 해서, 여기에는 문서와 커밋에 남은 판단을 옮겼다.

## 요약

- **시험 데이터 고정**: 학습 9/22~10/19(28일), 시험 10/20~11/1(13일, 거르기 후 6,852장). 지금 서비스 모델 ⓐ의 시험 MAE **3.61**(평균만 부르면 5.30), 습도 70% 이상 치우침 +2.55
- 비 거르기를 서비스 추정기와 같게(60분 강수량 > 0) 바꿨다. **ⓐ 점수를 본 뒤에 바꿨다**는 것을 그대로 적었다(3.77 → 3.61)
- **카메라별 보정(M2)**: ⓐ에 카메라마다 기울기+절편을 얹자 3.61 → **3.19**, 습한 날 치우침 +2.55 → +1.40
- **대조군 ⓑ**(같은 방법으로 28일): 시험 **3.19**. 날 수만 늘려도 ⓐ+보정과 같은 점수가 나왔고, ⓑ에는 보정이 효과가 없었다
- 즉석 추론 사전 측정(S5a) 통과: VM에서 사진 받기부터 추정까지 11.9초, 최대 메모리 316MB

## 배경

11/1에 정한 계획대로 모델 실험을 시작했다. 원칙은 세 가지다. 후보를 먼저 정한다. 시험 데이터 하나로 모두 채점한다. 점수를 본 뒤 규칙을 바꾸면 전후를 같이 적는다.

## 한 일

### M0·M1 — 데이터와 시험 기간

- VM 사진을 11/2까지 받고 화각 검수 결과를 반영했다
- 옛 시험지 A(4일)는 학습에 합치고, 시험은 10/20~11/1 13일 하나로 한다. 연습시험 3묶음은 날짜 번호 % 3이다
- **비 거르기를 바꾼 경위**:
  - 처음에는 강수감지(RE)만 걸렀다. 이때 ⓐ는 3.77, 습한 날 치우침 +3.38이었다
  - 11/1처럼 비가 오다 그친 사이의 사진(잿빛 하늘, 짙은 습기, 실측은 낮음)을 +8 높게 부르고 있었다
  - 서비스 추정기는 이런 사진을 60분 강수량 > 0으로 걸러 추정하지 않는다. 그래서 학습·시험도 같은 기준으로 맞췄다(라벨에 `rn60` 추가)
  - 점수를 본 뒤 바꾼 것이라 두 점수를 다 남겼다. 레이더는 과거 자료가 없어 빠졌다

### M2 — 카메라별 보정

- 저장된 ⓐ 예측에 카메라마다 숫자를 얹는다. ① 절편만, ② 기울기+절편
- **보정 숫자는 시험 데이터로 맞추지 않는다.**
  - ⓐ는 ⓐ가 배우지 않은 학습 기간 14일(옛 시험지 A 4일 + 10/10~10/19)에 ⓐ가 낸 예측으로 맞춘다
  - ⓑ는 ⓑ의 연습시험 예측으로 맞춘다
- **①·② 고르는 규칙을 바꿨다.**
  - 처음 규칙은 "14일 안에서 하루씩 빼고 비교해 ②가 0.1 넘게 좋으면 ②"였다
  - ①의 시험 점수(3.31)를 본 뒤, ②의 점수를 보기 전에 바꿨다. 새 규칙은 둘 다 시험으로 채점한다는 것이다
  - 이유: 하나만 시험에 내면 실제로 나은 쪽이 시험조차 못 볼 수 있다. 후보가 둘이면 시험으로 골라서 점수가 부푸는 몫은 작다
  - 실제로 하루씩 빼기에서는 ②가 꼴찌(3.49)였는데 시험에서는 1등이었다
- 날짜별 승패와 부트스트랩 95% 범위를 출력하게 했다(`calibrate.py`)

### ⓑ — 날 수만 늘린 대조군

- ⓐ와 같은 설정으로 9/22~10/19를 학습했다(`incheon_log_top60_1019`). ⓐ 폴더는 덮어쓰지 않는다
- 연습시험 3.15, 12바퀴(최대치)

### 서비스 쪽

- **S5a 즉석 추론 측정**: `Estimator/infer_now.py 10042 --measure`를 VM에서 돌려 통과했다. 정기 추정기와 동시에 돌면 모델이 2개(약 600MB)가 되므로 잠금이 필요하다
- API 서비스의 메모리 상한(200M)을 올려야 하는 점, 실행 사용자 권한, 잠금 종료 코드 75를 팀장 할 일로 정리했다
- 추정기가 근거 사진용으로 가린 사본을 저장하게 했다(S3)
- 검색(S9)은 Nominatim으로 정했다. 키가 없고 엔터 때만 부르며 인천 범위로 제한한다

- ⓐ+②에서 많이 부르던 128·133·134·215번은 기울기가 0.74~0.79다(높게 부를수록 더 깎는다). 128번 MAE 4.54 → 2.75
- ⓐ→ⓑ에서 습한 날 높게 부르는 정도가 절반이 됐다(가장 건조 → 85~95% 차이 +3.5 → +1.8). 카메라끼리 치우침 차이도 6.2 → 3.2로 줄었다
- ⓑ의 전체 치우침 −1.29는 10/24·27·29·31 나흘(−2.6~−4.7)에서 주로 나왔다. 학습 기간에도 그런 날이 있었다(10/9·10/10·10/12)
- 인천 ASOS 시간자료로 날짜별로 보니 실측이 높은 날일수록 덜 부른다(치우침과 실측 상관 −0.54, 41일). 실측 효과를 빼면 시정이 좋은 날 더 낮게 부르는 경향이 약하게 있다(−0.27). 41일의 약한 상관이라 단정하지 않는다
- ⓑ에 보정이 효과가 없는 이유는, 남은 카메라 버릇이 학습 기간과 시험 기간에 달라서 학습 기간으로 정한 숫자가 맞지 않기 때문으로 봤다(해석이고, 따로 검증하지는 않았다)

## 정정된 판단

- **비 거르기**: 학습·시험을 강수감지(RE)로만 거른 것은 서비스 추정기 기준(10/18에 바꾼 60분 강수량)과 어긋나 있었다. ⓐ 점수를 본 뒤에 알아차려 바꿨다(위)
- **M2 ①·② 고르기 규칙**: 하루씩 빼기로 고르는 규칙은 실제로 나은 ②를 떨어뜨렸을 것이다(위)
