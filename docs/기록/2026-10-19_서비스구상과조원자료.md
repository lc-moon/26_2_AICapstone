# 2026-10-19 · 서비스 구상과 조원 자료

> 7주차 · 실서비스(백엔드·프론트) 구축을 시작하며 화면 형태와 서버 구성을 정하고, 시안을 실제 지도 위에 만들어 저장소에 남겼다.
> 조원 2명이 A(백엔드)·B(프론트)를 골라 PR로 작업하도록 Notion 가이드와 공통 자료를 만들고, 조원 입장에서 따라가 보며 막힐 곳을 메웠다. (10/18 밤~10/19 새벽 작업)

## 요약

- 서버는 **VM 한 대**(API·DB·화면 파일), 무료 도메인 + HTTPS. 목적이 전시라 서버를 나누지 않는다. 비용은 무료 티어 계정이면 월 약 $4(외부 IP)
- 화면은 **격자를 숨기고 구름처럼**. 계산은 1km 격자, 범위는 **인천 내륙 + 송도**(강화·옹진·영종 제외). 3안(구름·점 격자·3D 기둥) 시안을 보고 사용자가 골랐다
- 시안을 MapLibre + OpenFreeMap으로 실제 지도 위에 만들어 `Web/mockup/`에 남겼다. 10/16 13:20 실제 추정값으로 칠하고 클릭 패널까지 동작한다
- 조원 인계: 할 일은 기한 없이 순서만, 첫 마감 **10/26**(22일 수업이 없어 당겨 잡고, 그 결과로 팀장이 발표자료를 만든다), 중간점검은 PR 피드백으로 대신. Notion 가이드와 공통 자료(격자·경계·스키마·API 응답 예시)를 만들고, 조원 입장 검토로 11곳을 보완했다
- 경계를 2013 시군구에서 **2026-10-01 행정경계**(7월 개편 반영)로 바꿨다. 격자는 388칸

## 배경

모델 쪽이 일단락되어 "이번 주부터 실서비스용 프론트·백을 시작해야 한다"는 데서 출발했다.
10/10에 서비스 형태(수집기 → 추정기 → 백엔드 → 프론트)는 정했지만, 백엔드 조원과 정할 것으로 남긴 전송 방식·서버 위치·저장 항목·밤 화면이 그대로였다.
조원의 프로토타입(카톡으로 받은 `incheon-air`)은 2km 격자를 2D 지도에 그대로 띄운 한 시점짜리였다.

## 한 일

### 서버와 비용

- 무료 티어 e2-micro는 **결제 계정마다 한 대분**이라, 수집 VM 계정에 한 대 더 만들면 월 약 $10이다. 다른 결제 계정(조원 계정 등)이면 외부 IP 약 $3.65만 든다
- 월 1GB 무료 전송은 VM이 내보내는 양이다. 한국행은 넘으면 GB당 $0.19. 지도 배경은 OpenFreeMap이 보내므로 우리 몫은 화면 파일과 JSON뿐이다
- Claude가 화면만 정적 호스팅에 따로 두는 안을 설명했지만, 사용자가 "서버 두 곳이면 머리 아프고 전시가 목적"이라 해 **VM 한 대**로 정했다
- 페이지가 https면 브라우저가 http API를 막으므로 API도 https가 필요하다 → 무료 도메인(DuckDNS) + Caddy
- GCP 계정은 미정(사용자의 다른 계정 또는 조원 계정)

### 지도와 화면 형태

사용자가 보여 준 참고 이미지(서울 마라톤 경로 위 3D 건물)는 **OpenFreeMap Liberty 스타일을 MapLibre로 그린 것**과 같았다(여의도를 띄워 대조).
인천도 3D 건물이 나오지만, 이 스타일은 **확대 수준 14부터** 건물을 세운다. 인천 전체 화면은 약 10이라 평면이고, 클릭해 확대해야 3D가 보인다.

시안을 세 가지로 그려 보였다 — 구름형(격자 숨김), 점 격자, 3D 기둥(높이 = 농도).
사용자는 "들어오자마자 격자가 보이면 이상하다"며 **격자는 계산용으로만, 화면은 구름처럼**으로 정했다. 이어서 고친 것:

- 색을 파스텔로(너무 파랑·초록이면 눈이 아프다), 같은 등급 안에서도 농도 명암, 확대할수록 옅게
- 인천 밖은 라벨까지 가리고, 첫 화면은 살짝(40°) 기울이기, 도로 번호 표지(`13;25` 같은 숫자) 제거
- 클릭 패널은 추정값·등급·가까운 측정소 실측·각각의 기준 시각을 나란히
- 화면에는 기준 시각·범례·출처만. CCTV·측정소 위치와 숫자는 띄우지 않는다

**범위**: 사용자는 섬을 빼고 내륙 + 송도만 쓰려 했다. 확인하니 20대 중 섬에 있는 카메라는 103번(초지교사거리, 강화군) 하나, 영종도는 0대였다.
103번은 화면 범위 밖이지만 **보간 입력으로만** 남기기로 했다. 바다·범위 밖은 클릭되지 않는다.

**격자**: 1km(사용자 "좀 더 상세하게"). 조원 프로토타입은 2km였다.

### DB와 API

지난 N일 변화를 기상 방송 구름처럼 보여 주는 기능(사용자 구상)을 위해, 격자 모양은 한 번만 보내고 회차마다 **농도 배열만** 보내는 구조로 했다(`frames.values`).
추정값·실측값 원본(`estimates`, `observations`)과 계산 결과(`frames`)를 나눠, 보간 방법이 바뀌면 다시 계산할 수 있게 했다.
Claude가 권한 `model_versions`·`daily_metrics`(하루 단위 추정 대 실측, 지금 손으로 하는 대조의 자동화)·`ingest_log`까지 넣기로 했다.

클릭 계산은 백엔드에 두었다. 응답이 1KB 내외라 확대 애니메이션(약 2초) 동안 도착한다. `stale`(오래된 값)은 낮에 2회차 연속 추정값이 하나도 안 오면 켜진다.

### 조원에게 넘기는 방식

사용자가 원한 형태는 "조원에게 던져 주면 PR을 올리고, 확인하며 머지하고 기능을 얹는" 것이었다.

- 조원 2명이 **A(백엔드·DB)와 B(프론트) 중 고른다.** 서로 기다리지 않도록 API 약속과 목업 응답을 먼저 준다. 언어는 각자 자유
- Claude가 기한을 단계로 쪼갰는데, 사용자가 "그냥 다 나열, 되는 데까지 하겠지"라고 해 순서만 남겼다
- 첫 마감은 처음 10/27로 잡았다가 10/26으로 당겼다(22일 수업이 없고, 마감 결과로 팀장이 발표자료를 만든다). 10/21 중간점검은 PR 피드백으로 대신한다
- 조원들은 Notion 페이지를 LLM에 넘겨 요약시킨 뒤 작업할 것이라, 가이드는 짧게(절반으로 줄임) 쓰고 자세한 것은 파일로 보냈다
- 문서는 Notion을 먼저 검수받고 그다음 `docs/`에 반영한다(한 번에 두 곳을 고치지 않으려고)

공통 자료는 `Tools/make_service_shared.py`가 `data/service_shared/`에 만든다(새 저장소의 `shared/`로 옮길 예정).
목업 응답은 VM의 실제 추정값으로 계산했고, **백엔드가 같은 입력을 넣어 같은 격자값이 나오면 맞는 것**이 되도록 시안과 같은 보간식을 썼다.

### 시안이 느리고 깨지던 문제

사용자가 시안을 Chrome에서 열자 앱 브라우저보다 많이 느렸다. 웹서버 때문은 아니었다. 시안 코드에서 세 곳을 찾았다.

| 원인 | 수정 |
|---|---|
| 시작할 때 구름 이미지를 크게 계산(0.5초 멈춤) | 작게 계산 후 흐리게 → 0.1초 |
| 인천 밖 글자 거르기가 경계 꼭짓점 12,898개를 매번 확인 | 글자 판정용으로 줄인 경계(342개) |
| 카드 뒤 반투명 흐림(`backdrop-filter`) | 거의 불투명한 흰색으로 |

사용자의 Chrome 하드웨어 가속이 꺼져 있었을 가능성도 있다(확인 방법만 안내했고 결과는 듣지 못했다).

이어서 "켜자마자 서구 남쪽이 하얗게 가려지는" 일이 가끔 있었다. 가림막을 "큰 사각형에 구 모양 구멍 8개를 뚫은 도형"으로 그렸는데,
구멍끼리 경계를 맞대고 있어 지도가 타일로 잘라 그릴 때 구멍이 메워지는 것으로 보고, 가림막도 이미지로 그리게 바꿨다. 이후 배율별로 확인한 범위에서는 재현되지 않았다.

### 조원 입장에서 따라가 보기

사용자가 "프로젝트를 대충 아는 조원이 메시지·저장소·파일을 받고, 문서를 읽고, LLM에 넘겨 '내 역할 것을 만들어 달라'고 하는 흐름"에서 막힐 곳을 찾아 달라고 했다.

- **A**: 모델 목록 표가 비어 있어 추정값 첫 저장부터 외래키 오류 → 시드 추가. 에어코리아는 측정소를 전부 주는데 표에는 53곳뿐 → "목록에 있는 것만". `dataTime`의 `24:00`과 `-` 값.
  한 회차 20대가 두 번에 나뉘어 오는데(추정기가 5분마다 돔) 처음 것만으로 계산하고 끝낼 위험 → "올 때마다 다시 계산"과 하루치 시험 파일. 밤 정의(태양고도 0° 미만), 수신 토큰을 누가 정하는지, 응답 시각 UTC
- **B**: 시안은 카메라 값으로 직접 계산하는데 B가 받는 것은 격자값이라 그대로 못 쓴다 → 격자 응답에 행·열을 넣고 그리는 법을 적음.
  오늘 겪은 느림·깨짐이 반복되지 않게 줄인 경계·외곽선을 파일로, 갱신 주기(1분), 목업을 파일로 열면 브라우저가 막는 것

### 경계 교체

Claude는 처음 2013 시군구 경계로 시안을 만들고 "실서비스 전에 최신 경계로 바꿔야 한다"고 넘겼다. 사용자가 "지금은 못 바꾸냐"고 묻자
찾아보니 통계청 SGIS 원자료를 정리한 공개 저장소(vuski/admdongkor, CC BY 4.0)에 **2026-10-01판**이 있었다.
7월 개편(서해구·검단구·제물포구·영종구)이 반영돼 있어 영종구를 빼기가 쉬워졌고, 송도 매립지가 경계에 들어갔다. 구를 합쳐 바깥 테두리 하나만 긋는다.
화면 출처에 "행정경계: 통계청 SGIS"를 넣었다.
