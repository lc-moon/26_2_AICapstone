# 모델 → 백엔드 데이터 형식 (10/1 프로토타입)

AI 모델이 백엔드에 넘기는 데이터의 형식이다. **단방향이고, 모델로 돌아오는 데이터는 없다.**

10/1 프로토타입은 **2026-09-22 12:00 한 시점**만 다룬다. 시간 변화는 구현하지 않는다.

---

## 데이터 흐름

```
[모델]  CCTV 사진 → 카메라별 추정 농도
          │  values.json  (카메라 번호 + 농도)
          ▼
[백엔드] 카메라 번호 → 격자 번호로 바꾸고, 격자별 농도 계산
          │  (격자 매핑은 cameras.json 좌표로 미리 만들어 둘 것)
          ▼
[프론트] 3D 지도 위 격자에 색 + 농도 표시, 범례
```

격자 크기, 보간(IDW), 색상은 전부 백엔드·프론트 몫이다. 모델 출력에는 들어가지 않는다.

---

## 파일 두 개

### `model_output/values.json` — 모델이 내놓는 값

나중에 20분마다 새로 생기는 파일이다. 지금은 12:00 한 장뿐이다.

```json
{
  "time": "2026-09-22T12:00:00+09:00",
  "unit": "ug/m3",
  "note": "10/1 프로토타입용 가상값. 카메라 번호는 실제, 농도는 가상",
  "data": [
    { "camera_id": "121", "pm25": 29.7 },
    { "camera_id": "113", "pm25": 22.6 }
  ]
}
```

| 필드 | 설명 |
|---|---|
| `time` | 촬영 시각 (KST). 프로토타입에서는 고정 |
| `unit` | 항상 `"ug/m3"` (㎍/㎥) |
| `data[].camera_id` | 카메라 번호. **`cameras.json`과 이어붙이는 키** |
| `data[].pm25` | 추정 농도. 지금은 가상값 |

### `model_output/cameras.json` — 카메라 위치 (거의 안 바뀜)

카메라를 추가·제외할 때만 바뀐다. 백엔드가 **격자 매핑을 미리 계산해 두면 된다.**

```json
{
  "cameras": [
    { "camera_id": "121", "name": "남동공단입구사거리",
      "lat": 37.422518, "lon": 126.709353 }
  ]
}
```

| 필드 | 설명 |
|---|---|
| `camera_id` | 모델 출력의 `camera_id`와 같은 값 |
| `name` | CCTV 이름. **표시용이지 키가 아니다** |
| `lat` / `lon` | WGS84 위경도. 격자 매핑은 이 좌표로 |

---

## 프론트 — 등급 기준

환경부 초미세먼지(PM2.5) 기준이다. 범례에 이 네 단계를 쓰면 된다.

| 등급 | 농도 (㎍/㎥) |
|---|---|
| 좋음 | 0 ~ 15 |
| 보통 | 16 ~ 35 |
| 나쁨 | 36 ~ 75 |
| 매우나쁨 | 76 이상 |

지금 넣어둔 가상값은 **9.3 ~ 29.7**이라 좋음 6대 · 보통 14대로 나뉜다.
색이 두 가지는 나오도록 일부러 퍼뜨린 값이다.

---

## 백엔드가 알아둘 것

**`camera_id`가 유일한 키다.** 이름(`name`)으로 잇지 말 것. 표시용이고 바뀔 수 있다.

**`L1001` 같은 코드는 쓰지 않는다.** 그건 영상 스트림 주소에 들어가는 값인데 제공 측에서
바뀔 수 있어서 키로 삼으면 위험하다. 우리가 쓰는 번호는 인천교통정보센터가 부여한 관리번호이고,
모델·이미지 저장 경로·이 파일이 전부 같은 값을 쓴다.

**카메라가 항상 20대인 건 아니다.** 지금은 20대지만 카메라가 고장 나면 그 회차에서 빠질 수 있다.
(실제로 9/22에 한 대가 6시간 멈췄다.) `data` 길이를 20으로 고정하지 말고 배열을 순회하는 편이 안전하다.

---

## 10/1 → 11/11에 바뀌는 것

**형식은 그대로 둔다.** 파일 이름, 필드 이름, 타입, 단위 전부 유지되므로 백엔드·프론트 코드는
고치지 않아도 된다.

바뀌는 건 둘뿐이다.

- `pm25` 값이 가상값에서 **사진으로 추정한 실제 값**이 된다
- 파일이 **20분마다 새로 생긴다** (지금은 한 장 고정)
